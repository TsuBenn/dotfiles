# Computer Organization and Architecture - Complete MCQ Bank (21 Chapters)

## Chapter 1: Basic Concepts and Computer Evolution

**1. What is the primary difference between computer architecture and computer organization?**
A) Architecture is visible to the programmer, organization is how features are implemented
B) Organization is visible to the programmer, architecture is how features are implemented
C) They are exactly the same concept
D) Architecture deals with hardware, organization deals with software

**Answer: A**
*Explanation: Computer architecture refers to those attributes visible to the programmer (instruction set, data types, I/O mechanisms), while computer organization refers to how these features are implemented (control signals, memory technology).*

**2. The IBM System/370 architecture was introduced in 1970 with what key benefit?**
A) It was the first computer to use vacuum tubes
B) Customers could upgrade to faster models without abandoning original software
C) It was the first multiprocessor system
D) It introduced the concept of virtual memory for the first time

**Answer: B**
*Explanation: The System/370 architecture maintained compatibility across models, allowing customers to upgrade to faster models while preserving their software investment—a principle that continues in IBM's mainframe product line today.*

**3. Which of the following is NOT one of the four basic functions a computer performs?**
A) Data processing
B) Data storage
C) Data encryption
D) Data movement

**Answer: C**
*Explanation: The four basic functions are data processing, data storage, data movement, and control. Data encryption is a specific operation, not a fundamental function category.*

**4. What are the four main structural components of a computer?**
A) CPU, RAM, ROM, Hard Drive
B) CPU, Main Memory, I/O, System Interconnection
C) Processor, Cache, Bus, Peripherals
D) ALU, Control Unit, Registers, Cache

**Answer: B**
*Explanation: The four main structural components are the Central Processing Unit (CPU), Main Memory, Input/Output (I/O), and System Interconnection (the mechanism for communication among them).*

**5. In the context of multicore systems, what is the definition of a "core"?**
A) The entire processor chip
B) The main memory controller
C) An individual processing unit on a processor chip
D) The cache memory subsystem

**Answer: C**
*Explanation: A core is an individual processing unit on a processor chip that can execute instructions independently. A processor may contain one or multiple cores.*

**6. What is the fundamental contribution of the IAS computer?**
A) First computer to use integrated circuits
B) Stored program concept
C) First commercial computer
D) Introduction of pipelining

**Answer: B**
*Explanation: The IAS computer (completed in 1952) implemented the stored program concept attributed to John von Neumann, becoming the prototype for all subsequent general-purpose computers.*

**7. The von Neumann architecture is based on three key concepts. Which of the following is NOT one of them?**
A) Data and instructions are stored in a single read-write memory
B) Memory contents are addressable by location
C) Execution occurs in parallel fashion across multiple instructions
D) Execution occurs sequentially unless explicitly modified

**Answer: C**
*Explanation: The von Neumann architecture specifies sequential execution, not parallel. Instructions are fetched and executed one after another unless a branch instruction explicitly changes the sequence.*

**8. Which statement about cache memory is TRUE?**
A) Cache is larger and slower than main memory
B) Cache is smaller and faster than main memory
C) Cache is used only for permanent storage
D) Cache replaces main memory entirely

**Answer: B**
*Explanation: Cache memory is smaller and faster than main memory, placed between the processor and main memory to speed up memory access by storing data likely to be used in the near future.*

**9. Moore's Law originally stated that:**

## Chapter 2: Performance Concepts

**21. According to Amdahl's Law, what limits the potential speedup of a program using multiple processors?**
A) The number of processors available
B) The speed of individual processors
C) The fraction of the program that cannot be parallelized
D) The size of the program

**Answer: C**
*Explanation: Amdahl's Law states that the speedup is limited by the portion of the program that must execute sequentially. Even with infinite processors, speedup is bounded by 1/(1-P) where P is the parallelizable fraction.*

**22. What is the formula for Amdahl's Law speedup?**
A) Speedup = 1 / (1 - P + P/N)
B) Speedup = P × N
C) Speedup = N / (1 - P)
D) Speedup = 1 / P

**Answer: A**
*Explanation: Amdahl's Law: Speedup = 1 / [(1 - P) + P/N] where P is the parallelizable portion and N is the number of processors. The sequential portion (1-P) always remains.*

**23. Little's Law states that:**
A) The average number of items in a queuing system equals arrival rate times average time in system
B) The speedup is limited by the sequential portion of a program
C) Power consumption is proportional to frequency squared
D) Memory latency increases with capacity

**Answer: A**
*Explanation: Little's Law: L = λ × W, where L is average number of items in the system, λ is average arrival rate, and W is average time an item spends in the system.*

**24. Which of the following is a technique to address the mismatch between processor and memory speeds?**
A) Increasing clock speed only
B) Adding cache memory
C) Reducing transistor count
D) Using only magnetic storage

**Answer: B**
*Explanation: Cache memory acts as a buffer between the fast processor and slower main memory, exploiting locality to reduce effective memory access time.*

**25. What is the arithmetic mean (AM) best used for when comparing system performance?**
A) Comparing rates where equal time is meaningful
B) Comparing normalized results across systems
C) Measuring execution time when total time is meaningful
D) Measuring throughput performance

**Answer: C**
*Explanation: The arithmetic mean is appropriate for time-based variables like execution time because it's directly proportional to total time—if total time doubles, the mean doubles.*

## Chapter 3: A Top-Level View of Computer Function and Interconnection

**41. What are the three key concepts of the von Neumann architecture?**
A) Parallel execution, separate memory for data and instructions, fixed program
B) Stored in single memory, addressable by location, sequential execution
C) Distributed memory, parallel execution, hardware program
D) Separate instruction and data memory, random access, parallel execution

**Answer: B**
*Explanation: The three concepts are: (1) data and instructions stored in single read-write memory, (2) memory addressable by location regardless of data type, (3) sequential execution unless modified.*

**42. What does the Program Counter (PC) hold?**
A) The current instruction being executed
B) The address of the next instruction to be fetched
C) The result of the last arithmetic operation
D) The memory address of data

**Answer: B**
*Explanation: The Program Counter (PC) holds the address of the next instruction to be fetched. After each instruction fetch, the PC is incremented to point to the next sequential instruction.*

**43. In the instruction cycle, what happens during the fetch cycle?**
A) The processor executes the instruction
B) The processor fetches an instruction from memory
C) The processor saves the program state
D) The processor handles interrupts

**Answer: B**
*Explanation: During the fetch cycle, the processor fetches the next instruction from memory using the address in the Program Counter and loads it into the Instruction Register.*

**44. Which of the following is a class of interrupts?**
A) Data processing interrupt
B) Program interrupt
C) Memory interrupt
D) Architecture interrupt

**Answer: B**
*Explanation: Classes of interrupts include program interrupts (overflow, division by zero), timer interrupts, I/O interrupts, and hardware failure interrupts.*

**45. What is Direct Memory Access (DMA)?**
A) Processor directly accessing memory without cache
B) I/O module exchanging data directly with memory without processor involvement
C) Memory accessing I/O devices directly
D) Cache directly accessing main memory

**Answer: B**
*Explanation: DMA allows I/O modules to read from or write to memory directly, without tying up the processor. The processor grants authority to the I/O module for memory transfers.*

**46. What determines the maximum possible memory capacity in a system?**
A) Data bus width
B) Control bus width
C) Address bus width
D) Processor clock speed

**Answer: C**
*Explanation: The width of the address bus determines the number of unique addresses that can be referenced, thus determining the maximum possible memory capacity (2^address lines).*

**47. What is the function of the data bus?**
A) To designate the source or destination of data
B) To provide a path for moving data among system modules
C) To control access to data and address lines
D) To provide timing signals

**Answer: B**
*Explanation: The data bus provides the path for moving data among system modules. Its width determines how many bits can be transferred simultaneously.*

**48. What is QuickPath Interconnect (QPI)?**
A) A shared bus architecture
B) A point-to-point interconnect with layered protocol architecture
C) A type of main memory
D) An I/O interface standard

**Answer: B**
*Explanation: QPI is a point-to-point interconnect introduced in 2008 that uses direct pairwise connections, eliminating arbitration, with a layered protocol architecture and packetized data transfer.*

**49. In PCI Express, what is a "split transaction"?**
A) A transaction split across multiple buses
B) A request packet sent with a response (completion packet) expected
C) A transaction that requires multiple clock cycles
D) A transaction split between memory and I/O

**Answer: B**
*Explanation: Split transactions involve sending a request packet and waiting for a completion packet response, allowing other transactions to proceed while waiting.*

**50. What are the four address spaces supported by PCI Express Transaction Layer?**
A) Memory, I/O, Configuration, Message
B) Data, Instruction, Control, Status
C) Local, Remote, Cache, Main
D) Input, Output, Storage, Processing

**Answer: A**
*Explanation: PCIe supports four address spaces: Memory (main memory and I/O devices), Configuration (I/O device registers), Message (control signals for interrupts, error handling), and I/O (legacy PCI devices).*

**51. What is the purpose of the Control Bus?**
A) To move data between modules
B) To designate source or destination of data
C) To transmit command and timing information
D) To provide power to modules

**Answer: C**
*Explanation: The control bus transmits command and timing information, including signals that indicate validity of data and address information and specify operations to be performed.*

**52. What is a key advantage of point-to-point interconnects over shared buses?**
A) Lower cost
B) No arbitration required
C) Simpler protocol
D) Longer distance capability

**Answer: B**
*Explanation: Point-to-point interconnects use direct connections between components, eliminating the need for arbitration that is required in shared bus systems where multiple devices compete for access.*

**53. In QPI, what is a "flit" (flow control unit)?**
A) A complete packet of data
B) A 72-bit message payload with 8-bit error control code
C) A routing instruction
D) A cache line

**Answer: B**
*Explanation: A flit consists of a 72-bit message payload and an 8-bit cyclic redundancy check (CRC) for error control, operating at the link layer for flow and error control.*

**54. What does the QPI link layer's flow control function ensure?**
A) Data is routed correctly
B) Sender does not overwhelm receiver's buffer capacity
C) Cache coherency is maintained
D) Physical connections are maintained

**Answer: B**
*Explanation: Flow control ensures that a sending QPI entity does not send data faster than the receiver can process it and clear buffers for more incoming data.*

**55. In PCIe, what are "posted transactions"?**
A) Transactions that require immediate response
B) Transactions that expect no response (no completion packet)
C) Transactions posted to memory
D) Highest priority transactions

**Answer: B**
*Explanation: Posted transactions, such as some write transactions and TL messages, do not expect a response or completion packet, improving efficiency for certain operations.*

**56. What is the primary function of the QPI routing layer?**
A) Error detection and recovery
B) Flow control
C) Determining packet path across system interconnects
D) Cache coherency protocol

**Answer: C**
*Explanation: The routing layer determines the course that a packet will traverse across available system interconnects, with possible paths defined by firmware.*

**57. In the context of I/O, what is "memory-mapped I/O"?**
A) I/O devices use separate address space
B) I/O devices and memory share the same address space
C) I/O devices are mapped to cache
D) Memory is mapped to I/O devices

**Answer: B**
*Explanation: Memory-mapped I/O shares the same address space between devices and memory, allowing I/O operations to use the same instructions as memory accesses.*

**58. What is the function of the Instruction Register (IR)?**
A) Hold the address of the next instruction
B) Hold the instruction most recently fetched
C) Hold data being written to memory
D) Hold the memory address for I/O

**Answer: B**
*Explanation: The Instruction Register (IR) contains the instruction most recently fetched from memory, holding it while the control unit decodes and executes it.*

**59. In the indirect cycle, what happens when an instruction specifies indirect addressing?**

D) The instruction is ignored

**60. What is an I/O module's role in data transfer?**
A) Store data permanently
B) Exchange data between processor and external environment

**Answer: B**

## Chapter 4: The Memory Hierarchy: Locality and Performance

**61. What is the principle of locality (locality of reference)?**
A) Memory references are evenly distributed throughout execution
B) Memory references by the processor tend to cluster during execution
C) All memory locations are accessed equally often
D) Programs access random memory locations

**Answer: B**
*Explanation: Locality of reference reflects the observation that during program execution, memory references tend to cluster, with programs repeatedly accessing the same or nearby memory locations.*

**62. What is temporal locality?**
A) Accessing memory locations with nearby addresses
B) Referencing memory units accessed in the recent past
C) Accessing memory in sequential order
D) Accessing memory at specific times

**Answer: B**
*Explanation: Temporal locality refers to the tendency to reference in the near future memory units that were referenced in the recent past, such as loops and frequently accessed variables.*

**63. What is spatial locality?**
A) Accessing the same memory location repeatedly
B) Accessing memory units whose addresses are near one another
C) Accessing memory at specific spatial coordinates
D) Random memory access patterns

**Answer: B**
*Explanation: Spatial locality refers to the tendency to reference memory units with addresses near each other, such as when processing sequential data in arrays or executing sequential instructions.*

**64. Which of the following is a characteristic of volatile memory?**
A) Information remains without power
B) Information decays or is lost when power is switched off
C) Cannot be altered after programming
D) Requires periodic refresh even with power

**Answer: B**
*Explanation: Volatile memory loses its contents when power is removed. Information naturally decays or is lost when electrical power is switched off.*

**65. What trade-off exists in memory hierarchy design?**
A) Faster access time, greater cost per bit; greater capacity, slower access time
B) Faster access time, lower cost per bit
C) Larger capacity, faster access time
D) All memory types have identical characteristics

**Answer: A**
*Explanation: There is an inherent trade-off: faster access memory costs more per bit and typically has less capacity, while larger capacity memory is slower and costs less per bit.*

**66. In a two-level memory system, what is the purpose of the upper-level memory (M1)?**
A) To permanently store all data
B) To serve as temporary store for part of the larger M2's contents
C) To replace the lower-level memory
D) To store only system programs

**Answer: B**
*Explanation: Upper-level memory (M1) is smaller, faster, and more expensive, serving as a temporary store for frequently accessed portions of the larger, slower M2 memory.*

**67. What is the unit of transfer for internal memory?**
A) Always one byte
B) The number of electrical lines into and out of the memory module
C) One word
D) Variable based on instruction

**Answer: B**
*Explanation: The unit of transfer for internal memory equals the number of electrical lines into and out of the memory module, determining how many bits can be read or written simultaneously.*

**68. Which type of memory is nonvolatile and cannot be altered except by destroying the storage unit?**
A) SRAM
B) DRAM
C) ROM (Read-Only Memory)
D) Cache

**Answer: C**
*Explanation: ROM is nonvolatile and nonerasable; its contents are permanently set during fabrication and cannot be altered except by physically destroying the storage unit.*

**69. What is the primary benefit of using a multilevel memory hierarchy?**
A) Simplified design
B) Balanced cost, performance, and capacity
C) Reduced power consumption
D) Increased complexity

**Answer: B**
*Explanation: A memory hierarchy balances the three conflicting constraints: how much, how fast, and how expensive, by using different technologies at different levels.*

**70. What is a "block" in the context of memory hierarchy?**
A) A single byte of data
B) The minimum unit of transfer between levels of memory
C) A sector on disk
D) A cache line tag

**Answer: B**
*Explanation: A block is the minimum unit of information that can be transferred between levels of the memory hierarchy, such as between cache and main memory.*

**71. What is the access time of a memory system?**
A) The time to transfer a block of data
B) The time from when an address is presented until data is available
C) The time between successive accesses
D) The time to power up the memory

**Answer: B**
*Explanation: Access time is the time interval between the presentation of an address and the availability of the data at the memory output.*

**72. In memory hierarchy design, what does "hit ratio" measure?**

C) The number of misses
D) The ratio of read to write operations

**Answer: B**
*Explanation: Hit ratio is the fraction of memory accesses that find the desired data in the upper-level (faster) memory, with higher hit ratios indicating better performance.*

**73. What is the primary difference between internal and external memory?**

**Answer: B**
*Explanation: Internal memory (registers, cache, main memory) is directly accessible by the processor, while external memory (disk, tape) requires I/O controllers for access.*

**496. (Chapter 8) What is the difference between programmed I/O and interrupt-driven I/O?**

**498. (Chapter 11) What is the floating-point subnormal (denormal) number range used for?**

**499. (Chapter 13) What is the difference between a subroutine call and a jump?**
A) Call saves return address; jump does not
B) No difference
C) Jump saves return address

**Answer: A**

**500. (Chapter 17) What is the primary benefit of RISC's load/store architecture?**
